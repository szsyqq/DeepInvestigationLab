智谱：书生下海，与一门它还在学的生意

一家从清华实验室跑出来的AI公司，2025年营收7.24亿元、却亏掉47.18亿元；当它带着"全球大模型第一股"的标签登陆港股，学者与商人两种身份，第一次被放在同一份财报里称量。书生造出了能对标OpenAI的模型，却还没学会写一份赚钱的财报。

调查团队 2026年7月 · 约 10 分钟阅读

2026年1月8日，港交所敲钟。北京智谱华章科技股份有限公司以"02513"为代码挂牌，发行价116.2港元，首日收盘涨13.17%、市值约579亿港元，被市场称为"全球大模型第一股"。[2]同一份招股书里还写着另一组数字：2024年收入3.12亿元，年内亏损29.58亿元；2025年全年收入7.24亿元，亏损扩大到47.18亿元。[1][3]

一边是营收三年翻了十倍，一边是亏损同步放大到十几倍。一家从清华大学计算机系知识工程实验室（KEG）走出来的公司，正站在它最陌生的考场上——怎么把"做出最强模型"的能力，翻译成"做成一门赚钱的生意"。

智谱的故事，是一个典型的中国式张力：学术声望拉满、估值高企，但商业化这道关，它还没真正迈过去。这道题，要从清华园里那间实验室讲起。

书生造出了能对标OpenAI的模型，却还没学会写一份赚钱的财报。

第一章清华的实验室，跑出一家对标OpenAI的公司

2019年6月，清华大学技术成果转化，把孵化自知识工程实验室的科技情报平台AMiner单独拆分，成立"智谱"。核心团队几乎全是清华人：CEO张鹏毕业于清华计算机系，董事长刘德兵曾任清华数据科学研究院科技大数据研究中心副主任，总裁王绍兰为清华创新领军博士，首席科学家唐杰是清华计算机系教授、AMiner的建立者。[1][4]

从第一天起，智谱就喊出"对标OpenAI"的口号，目标是AGI——"让机器像人一样思考"。在技术上，它选了一条与GPT不同的路：基于"自回归填空"范式的GLM架构。[4]这套架构后来适配了40余款国产芯片，成了业内通用性最高的模型体系之一。[2]

智谱的模型迭代，是一条清晰的"学院派"时间线——从框架到开源，再到智能体：[6]

清华基因，是智谱最硬的护城河，也是最重的标签。它意味着顶级的学术积累、政府的信任、以及"国家队"般的融资便利；但也意味着，当一家研究型公司要走向市场，它得先学会一门它并不天然擅长的功课——做生意。

第二章收入三年翻十倍，亏损翻了十几倍

智谱的营收增长，放在任何行业都算亮眼。招股书显示，2022年至2024年收入分别为5740万元、1.245亿元、3.124亿元，年复合增长率超过130%；2025年全年收入冲到7.24亿元，同比增长131.9%。[1][3]连续三年营收翻番，这是一门正在长大的生意。

但亏损跑得更快。同期年内亏损从1.44亿元、7.88亿元、29.58亿元，扩大到2025年的47.18亿元；经调整净亏损也达31.82亿元。[1][3]换句话说，收入涨了约十倍，亏损却涨了约三十倍。2024年研发费用率高达703%——每挣1块钱，要花7块在研发上。[1][13]

毛利率的走势，藏着另一重信号：从2023年的64.6%一路降到2025年的41.0%。公司解释，主因是低毛利的云端部署占比上升，以及本地化部署毛利率的阶段性下降。[3]研发与算力是亏损的两大源头——2024年研发21.95亿元，其中算力投入15.53亿元、占研发70.7%；2025年上半年研发15.95亿元，算力11.45亿元、占71.8%。[13]截至2025年底，公司股东权益已降至-81.11亿元，连续亏损正在侵蚀净资产。[3]

第三章一门还在学的生意：本地化部署与云端MaaS

智谱的收入，来自两种部署方式。一种是本地化部署，把模型装进客户的机房；另一种是MaaS云端部署，按 API 调用或订阅收费。早期，高毛利率的本地化部署是智谱的"基本盘"——2022年占收入95.5%。[5]

但智谱真正押注的，是云端 MaaS。它计划把 API 收入占比提升到一半，因为云端调用能随模型能力放大而指数级增长。代价是毛利率：云端部署毛利率从2022年的76.1%，一路滑到2025年上半年的-0.4%——换句话说，云端业务在贴钱换规模。[5]与此同时，本地化部署毛利率仍稳在59.1%（2025上半年）。[5]

这套"用低毛利云端换未来规模、用高毛利本地化守基本盘"的组合，逻辑上说得通，前提是云端调用量真能指数级放大、且智谱终能把价格提起来。2026年3月的业绩会上，CEO张鹏给出了一丝佐证：一季度 API 定价上调83%，调用量反而增长400%——他判断"高质量 token 是当下的稀缺资源，谁掌握了智能上界，谁就掌握了定价权"。[12]但"贴钱换规模"能否走通，仍是这门生意最大的问号。

第四章估值530亿，收入7亿：一道难算的题

智谱的融资史，本身就是一部估值狂奔史。成立至今完成8轮融资、累计超83.6亿元，投资方囊括美团、蚂蚁、阿里、腾讯、小米等产业资本，君联、红杉、高瓴、启明等头部机构，以及社保中关村基金、北京市人工智能产业投资基金等国资。[4]估值从A轮6.65亿元，一路抬到2025年5月B6轮后的243.77亿元——约三年半放大逾30倍。[4]

上市把估值又推高一截。2026年1月8日，智谱以116.2港元发行价登陆港股（依18C章18C章），全球发售3741.95万股、净筹资约41.73亿港元；11家基石投资者认购29.8亿港元、占发售股份近七成。首日市值约579亿港元。[2]但对照2025年7.24亿元收入，这笔市值对应的市销率约73倍——市场买的不是今天的收入，而是对 AGI 与"国产大模型第一股"的预期。

第五章开源者，为何选择上市

智谱是中国最早开源大模型的公司之一。从2022年开源千亿模型 GLM-130B，到2025年开源旗舰基座 GLM-4.5（3550亿参数），它把核心能力摊在开源社区面前。效果立竿见影：据招股书，GLM 在 OpenRouter 上的 token 消耗量稳居全球前十、中国前三，付费 API 收入超过所有国产模型之和；GLM-4.5 发布48小时即登顶 HuggingFace 热门榜全球第一。[7]

开源带来生态与口碑，却也带来两难：模型权重公开，意味着竞争对手能用、客户也比价，定价空间被压缩。这正是智谱与DeepSeek的分野——后者同样大开开源之门，却选择留在私募、把账本捂得严严实实；智谱则走向IPO，主动把财报摊在聚光灯下。一个用"不透明"换灵活，一个用"透明"换资本通道与公信力。[7]

选择上市，是智谱给这场长跑备的"粮草"。但透明也是一道紧箍咒：从此每一个季度的收入、每一笔研发的 burning，都要向市场交代。书生下了海，就再难回到只发论文的日子。

第六章六小虎里的"研究型选手"，与大厂的饱和战

智谱身处"大模型六小虎"之列。到2025年，基座模型创企已大幅收敛，除大厂外，独立玩家主要剩智谱、月之暗面、MiniMax。智谱的打法最像"研究型公司"：偏重B端和G端落地，没有参加2024年的C端投流大战。[9]

但这也意味着，在大众视野里它常被对手盖过。2025年3月数据，智谱清言月活约600万，仅为同为"六小龙"的KIMI约十分之一，也不及通义千问的900万。媒体曾以"成于清华，囿于清华"概括它的困境：人才结构呈U型，算法强、产品与工程弱。[8]与之对照，同期闯关港交所的 MiniMax 走C端路线，2025年9月平均月活已达2760万，收入超七成来自C端。[10]

真正的压力来自大厂。阿里宣布未来三年投入3800亿元，字节2025年也投入上千亿——这种饱和式军备，是任何创企都难长期匹敌的。智谱的优势在于"纯血"独立身份：企业客户担心科技巨头既做模型又做业务、形成竞争，反而更愿选不碰下游的"纯-play"供应商。[4]但优势能否抵消弹药差距，要看云端MaaS能不能跑出规模。据行业测算，2024年中国大模型市场约53亿元、预计2030年破千亿，年复合增速超60%[14]；赛道在变大，但赢家未必是今天的领跑者。

第七章粮草与紧箍咒：一场更贵的长跑

IPO 给智谱补了关键弹药：净筹资约41.73亿港元，其中70%用于通用大模型研发。上市次日股价一度冲到263港元、市值近980亿港元，之后回落至220港元区间。[2][11]更关键的是，它没打算停。2026年1月，中金递交第三期A股上市辅导报告，智谱继续推进"A+H"两地上市——既要港股的国际资本，也要A股的本土纵深。[11]

账面并不轻松。2025年末现金22.59亿元，而股东权益已为-81亿元——连续亏损的窟窿，要靠持续融资与不断改善的毛利去填。[3]张鹏把2026年的关键词定为"token量"，赌的是调用量的指数级增长能撑起定价权与规模效应。[12]这条路上，智谱并不孤单，却也并不安全：大厂在烧钱、同行在冲刺、资本在要答案。

核心矛盾 智谱的难题，不是"模型够不够强"——它已经是国产基座模型的第一梯队。真正的考题是：当学术声望变成估值、估值变成财报压力，一门以研发为唯一引擎的生意，能不能在 AGI 这场昂贵的长跑里，比对手多撑一轮、也比自己更早算平那笔账。

尾声书生还没学会写赚钱的财报

2026年1月8日敲钟那天，清华计算机系教授、智谱首席科学家唐杰发了一封内部信，预告 GLM-5 与下一代学习范式。书生依旧仰望 AGI 的星空。[11]

但市场已经把另一份考卷递到桌前。智谱用IPO换来了粮草，也戴上了一道透明的紧箍咒——此后每一个季度，它都得向所有人交代：模型是不是更强了，生意是不是更稳了。书生造出了能对标OpenAI的模型，却还没学会写一份赚钱的财报。问题或许不在"它能不能赚钱"，而在"在烧钱的长跑里，它能不能比对手多撑一轮"。

这家从清华实验室跑出来的公司，正走在一条没人替它标好终点的路上。金价不会为它停，算力也不会；能陪它走到最后的，只有一门它还在学的生意。
