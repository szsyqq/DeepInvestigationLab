# 版本归档 / Version Archive

本目录保存「深度调查报道」系列每篇文章的历次修改快照，按 **公司 + 时间** 命名，便于回溯到任意一版。

## 命名规则

```
版本归档/
  公司_YYYY-MM-DD[_描述]/
    index.html            # 当版完整文章（单文件 HTML，含 CSS/JS）
    （素材若有也一并放入）
```

- `公司`：报道主体，如 `长鑫科技` / `建滔集团` / `燧原科技` / `宇树科技`。
- `YYYY-MM-DD`：该版本的生成/修改日期。
- `_描述`（可选）：同日多版时区分动作，简短动作词：
  - `初版`：首次成稿
  - `脚注修正`：补/修正文脚注角标与文末来源列表
  - `表述脱敏`：按表述纪律修改署名/主体/标题
  - `数据更新`：更新财务/业务数据
  - `风格润色`：按写作风格准则（双关呼应/故事性/三性合一）润色

## 与各目录的关系

| 目录 | 角色 | 是否参与部署 |
|------|------|------|
| `底稿/日期_公司/` | **权威源**：每次改从这里改，再复制到门户 | 否（源） |
| `portal/reports/<key>/` | 线上发布版（从底稿复制） | 是（部署） |
| `版本归档/公司_时间/` | **历史快照**：只读留档，不参与部署 | 否（留档） |

> ⚠️ 覆盖底稿前，先把当前版存入 `版本归档/`，否则旧版无法回溯。

## 回溯方法

1. 直接打开对应 `公司_时间/index.html` 即该版完整文章。
2. 对比两版差异：`diff 版本归档/长鑫科技_2026-07-18_初版/index.html 版本归档/长鑫科技_2026-07-20_脚注修正/index.html`。
3. 如需回滚：把目标版本复制回 `底稿/日期_公司/index.html`，再复制到 `portal/reports/<key>/` 并重新部署。
