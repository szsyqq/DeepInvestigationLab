# 调查报道底稿 · 资料库

每篇调查报道以「**日期_上市公司**」为一个独立文件夹，既是报告底稿，也是这次调查的**原始资料库**。

## 目录规范（每家公司文件夹）

```
底稿/日期_公司/
├── index.html            # 报告最终底稿（权威版本，改动都改这里）
├── 资料清单.md            # 本篇全部资料来源索引（脚注沉淀 + 归档清单）
├── 原始资料/
│   ├── 舆情网页/          # 保存的新闻/舆情/自媒体页面（.html 或 .pdf/.png 快照）
│   ├── 招股书年报/        # 招股说明书、年报、业绩公告等一手文件（.pdf）
│   └── 研报数据/          # 券商研报、第三方机构数据（SemiAnalysis/Omdia/Prismark 等）
└── （可选）*.md           # 过程稿、信息汇编、问询分析等草稿
```

## 使用约定

1. **先建库、再写稿**：开一篇新报道前，先按上述结构建好文件夹与 `原始资料/` 子目录。
2. **边查边存**：每获取一份关键资料（网页/PDF/研报/数据），立即存入对应子目录，并在 `资料清单.md` 登记（来源、日期、对应文中哪个数据/脚注）。
3. **网页快照**：舆情网页尽量保存为可离线打开的 `.html` 或 `.pdf/.png`，避免链接失效后无法追溯。
4. **权威底稿唯一**：报告改动只改 `index.html`；发布走门户（见下）。
5. **发布**：底稿改好 → 复制到 `../portal/reports/<key>/index.html` → 重新部署 `../portal/`（门户是唯一发布平台，链接稳定不变）。

> 说明：2026-07-17/18 三篇为本规范落地前所写，原始网页当时未逐一存档；`资料清单.md` 已把当时使用的来源完整沉淀，后续如需回补，可按清单重新抓取存入 `原始资料/`。
