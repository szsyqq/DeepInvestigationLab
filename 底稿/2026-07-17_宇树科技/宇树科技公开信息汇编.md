## 六、核心技术分析

### "小脑"（运动控制）—— 世界领先

| 成就 | 时间 |
|------|------|
| 全球首次全尺寸电驱人形机器人原地后空翻 | 2024年 |
| 人形机器人奔跑速度超过5米/秒，刷新世界纪录 | 2025年 |
| 首届世界机器人运动会：4块金牌、11枚奖牌 | 2025年 |
| 25台机器人完成集群武术表演《武BOT》（花式翻桌跑酷、弹射空翻等） | 2026年春晚 |
| G1实现原地侧空翻并成为CMG机甲格斗擂台赛唯一参赛机型 | 2025年 |

### "大脑"（具身大模型）—— 起步较晚，正在补课

| 项目 | 说明 |
|------|------|
| **WMA大模型** | 2025年9月开源发布世界模型-动作（WMA）大模型"UnifoLM-WMA-0" |
| **VLA大模型** | 2026年1月开源发布视觉-语言-动作（VLA）大模型"UnifoLM-VLA-0" |
| **WVLA2.0** | 2026年5月25日发布迭代产品，可让G1在有人走动的复杂环境中自主完成会议室整理 |
| LIBERO基准测试 | UnifoLM-VLA-0平均分98.7分，已公开测试结果的具身大模型中排名第一 |

**关键自评**：
> 招股书承认：前期研发投入侧重"本体"与"小脑"，自2024年起才逐步加强对"大脑"（具身大模型）投入，报告期内研发投入占比相对较小。

> 目前已售产品集成的是自研运动控制模型（小脑）和第三方大语言模型（用于语音交互的"笨笨"功能），尚未将自研通用具身大模型规模化应用于机器人产品。
