# 景顺长城 · 补充深度分析

> 本文件为《景顺长城：告别刘彦春，一个明星基金时代的尾声》的补充分析，
> 聚焦刘彦春持仓不调仓的深层逻辑、景顺长城的"造星"商业选择、刘彦春的个人历史，
> 及基金公司经理层全景扫描。

---

## 1. 刘彦春为什么不调仓？——六层拆解

### 1.1 第一层：投资信仰——他是真的相信

刘彦春多次在季报/年报中明确表达一个观点：**高端白酒的基本面没有变**。
他的逻辑链条是：
- 中国经济长期向好 → 居民消费率提升 → 高端消费需求扩张
- 高端白酒（茅台、五粮液、泸州老窖）具有品牌护城河、定价权、存货升值属性
- 短期价格波动不影响长期价值

2026年4月的年报中，他写道："消费率提升是中长期趋势，2026年消费增速有望好于2025年，
前提是房价能稳住。"[来源：新浪财经，2026-04-03]——他确实相信消费复苏会来。

这不是借口。他2017年就押注消费，然后等到了2019-2020的爆发。
这种"先苦后甜"的经历强化了他的信念：**只要等得够久，市场风格会回来**。

### 1.2 第二层：路径依赖——成功经历是最大的陷阱

刘彦春的整个职业生涯，只对过一次——就是2017-2020年重仓消费。

在此之前（博时基金7年），他尝试过各种行业轮动（家居、养殖、计算机），业绩无一例外地垫底。
**他唯一一次成功的押注，就是消费**。从此他再也不敢离开这个赛道。

心理学上这叫"可得性启发"(availability heuristic)：一个人会根据最容易回忆起的经验来做决策。
对刘彦春来说，最容易回忆起的成功经验就是"重仓消费→暴涨"。他押注消费成功了1次，
在其他赛道失败了N次——这个不对称的反馈让他死死抱住消费。

一位分析师的评论很精辟："刘彦春的持仓微调——把五粮液换成古井贡酒、海康威视换成美的集团——
更像是用战术的勤奋掩盖战略的懒惰。"[来源：网易，《千亿顶流败给路径依赖》，2025]

### 1.3 第三层：规模过大——千亿基金的调仓困境

2021年高峰期，刘彦春管理1,163亿元。这个体量意味着：
- **如果要砍掉白酒仓位**：每个交易日只能卖几个亿，否则砸穿盘面
- **如果要买科技股**：科技股本身流通市值有限，百亿级别资金进去出不来回
- **换手率受限**：千亿规模下，换手率每提高1%，就是10亿级别的交易成本

一位私募基金经理在雪球上分析："刘彦春不是不想调仓，是调不动。
你让一个拿了几百亿白酒的人怎么调？一卖整个板块就崩了。"[来源：雪球用户分析]

但"调不动"是一个实然判断，不是应然借口——他可以选择在2021年高位逐渐减仓，
当时每天成交量充裕。他选择了不卖。这个选择不是"不能"，而是"不愿"。

### 1.4 第四层：薪酬结构——基民亏钱，我不亏钱

这是最残酷的一层。**刘彦春的收入与基金净值表现脱钩，与管理规模挂钩。**

公募基金经理的收入结构是：
- 基本工资（固定） + 奖金（与规模挂钩，一般按管理费收入的一定比例）
- 管理费 = 基金规模 × 管理费率（1.2%~1.5%）
- 管理规模1163亿时，年管理费约17亿，刘彦春个人年薪可能在千万到亿级别
- 管理规模265亿时，年管理费约3亿，个人年薪大幅缩水但仍有数百万至千万

**核心矛盾**：基金亏的是基民的钱，管理费赚的是基金公司的钱。
基金经理拿管理费分成，与赚钱或亏钱几乎没有直接关系。

2021-2025年，刘彦春管理的基金合计亏损424.7亿元，但为景顺长城贡献了46.69亿元管理费。
其中仅景顺长城新兴成长A一只产品亏了241.8亿，贡献了24.1亿管理费。
[来源：《聪明投基者》，Choice数据，2026-04-29]

这个制度的讽刺之处在于：**即使刘彦春现在清仓全部白酒买入国债，让净值不再下跌，
对他的薪酬改善也不大——他的收入取决于规模，而规模已经被熟透了。**
在"规模已定"的情况下，他要么赌一把"等消费回暖"，要么赌一把"换个赛道"。
从理性角度看，"以静制动"对他个人最安全：如果消费回暖，他翻盘成英雄；
如果继续跌，他可以说"我坚守了理念"。

### 1.5 第五层：公司态度——景顺长城不止不想他调仓，甚至希望他别动

景顺长城对刘彦春的态度，比外界想象的要暧昧。

一方面，公司已经意识到过度依赖刘彦春的风险——2025年起陆续给他增聘共管基金经理。
另一方面，公司一直强调"长期投资"的理念，对刘彦春的"坚守"给予了制度上的支持。

**为什么？**

因为如果刘彦春调仓，有两种可能的结果：
1. **调对了** → 净值反弹，基民回来，规模回升 → 完美
2. **调错了** → 两边打脸（抛售白酒时白酒涨、买入科技时科技跌）→ 灾难

在"调错"的风险面前，公司更倾向于让刘彦春"一动不动"。
因为"不动"至少有一个站得住脚的故事——"我们坚持长期价值投资"。
而如果调错了，连这个故事都没了。

更深层的原因是：**景顺长城没有准备好让刘彦春离开**。
他仍然是公司规模最大的主动权益基金经理（265亿）。
如果连他也像余广一样离任，景顺长城的主动权益将面临"权力真空"。

### 1.6 第六层：行业困境——不是刘彦春一个人的问题

最后，需要把问题放回大环境下看。

刘彦春的"困境"有一条完整的因果链：
- 白酒行业见顶（产能过剩、消费降级、飞天茅台从3000元跌至1500元附近）
- 贵州茅台2025年营收利润首次双降
- 消费赛道整体缩水
- 重仓消费的基金经理无一幸免

张坤（易方达）、萧楠（易方达）、胡昕炜（汇添富）、焦巍（银华）——
这些曾经的"消费大佬"同样亏损严重。刘彦春不是特例，他是最极端的一个。

**但刘彦春的极端程度是特殊的**：他的持仓集中度更高、换手率更低、坚守时间更长。
其他消费基金经理至少做了些调整——张坤逐渐减持白酒加仓科技，
萧楠降低了高端配置加仓养殖和农牧。刘彦春几乎纹丝不动。

## 2. 景顺长城为什么把千亿交给一个人？——"明星造星"的商业逻辑

### 2.1 "明星单核"是中国公募的行业病

把一家千亿级基金公司的命脉交给一个基金经理，听起来很危险。
但在中国公募行业，"明星单核"模式在过去十年是主流。

这个模式的逻辑链条：
1. **业绩出圈**：某一两年某个基金经理押对赛道 → 业绩爆棚 → 媒体报道 → 基民追捧
2. **规模膨胀**：资金涌入 → 管理规模迅速膨胀 → 按规模计提的管理费暴增
3. **公司背书**：基金公司顺势打造"明星基金经理"IP → 发行新产品 → 老产品限购打开
4. **循环反馈**：明星效应吸引更多资金 → 规模更大 → 管理费更多

景顺长城在这个模式上堪称"教科书级"：
- 刘彦春2019-2020年业绩爆发 → 媒体包装"千亿顶流"
- 公司将他提拔为副总经理、股票投资部基金经理
- 2020-2021年牛市高位发行多只新产品（景顺长城集英成长两年定开、绩优成长等）
- 管理规模巅峰1,163亿

### 2.2 "造星"对基金公司的好处

**首先是管理费的爆发式增长。**
2021年，刘彦春6只产品贡献的管理费可能在10亿以上。
对于一家总年营收约30-40亿的公司，这是一个举足轻重的数字。

**其次是品牌效应。**
"刘彦春的公司"这个标签本身就有营销价值。
在渠道销售中，"春哥管理"四个字能直接拉动销量。
基金经理的明星效应可以大幅降低渠道推广成本。

**第三是竞争壁垒。**
在公募行业，一个百亿级明星基金经理对竞争对手是一种威慑。
客户会因为"有明星经理"而选择这家公司。

### 2.3 "造星"的代价——风险集中与"尾大不掉"

代价同样巨大：

**第一个代价：流动性风险。**
余广离任的案例说明了一切。他管理的96.53亿中，
按30%的保守赎回率估算，景顺长城将流失约30亿。
如果赎回率达到50%，流失规模达48亿。

**第二个代价：救不救？怎么救？**
刘彦春的规模缩水到265亿，公司陷入两难：
- 如果继续支持他增聘经理、发行新产品 → 投资人对"刘彦春"这个招牌的信心已崩塌
- 如果放弃他、让他的产品自然萎缩 → 再流失200多亿规模，主动权益会更难看

**第三个代价：牌照机制的套利风险。**
公募基金是一个"有牌照壁垒"的行业。明星基金经理需要基金公司的牌照和渠道才能发行产品。
但近年来，"奔私潮"愈演愈烈——基金经理积累足够的名气和客户后，直接离职成立自己的私募。
鲍无可2025年5月离职，2026年5月加入高瓴瓴仁投资，就是这种套利的最新案例。

### 2.4 Invesco的影子——合资基因下的明星制度

景顺长城的合资身份（Invesco 49% + 长城证券 51%）使它的"造星"模式有一个额外的维度。

在美国，PIMCO的Bill Gross、富达的Peter Lynch，都是"明星单核"的经典案例。
这些模式的成功让Invesco对"造星"在中国的可行性持开放态度。

但美国市场与中国的差异在于：
- 美国机构投资者占主导，明星经理的离任对规模冲击较小
- 中国基民以散户为主，对"明星经理"的个人忠诚度极高
- 中国基金公司对明星经理的依赖度远高于美国同行

所以，**Invesco带来的不仅是投研支持，还有一个隐含的假设：**
**"明星模式在美国成功过，在中国也行得通。"**
这个假设在被景顺长城证实了——然后正在被证伪。

## 3. 刘彦春：从"倒霉蛋"到"顶流"到"活化石"

### 3.1 开局：七年垫底

刘彦春1976年出生，老家湖南，清华大学本科，北京大学管理学硕士。
90年代北大清华毕业，妥妥的天之骄子。

毕业后先后在汉唐证券和中信投资做研究员。
2006年进入博时基金——这是当时中国最大的基金公司之一。
2008年7月，他晋升为基金经理，管理博时新兴成长混合。

**这是灾难性的开局。**

他接手时，博时新兴成长是一只规模近200亿的大基金。
更不幸的是，当时正在经历2008年全球金融危机的余震。
大盘从6,124点暴跌至2,700点。刘彦春接盘后的短短四个月内，
基金净值从0.714元缩水到0.505元，亏损近30%。[来源：新浪财经，刘彦春履历回顾]

**他的第二只基金——博时第三产业混合——同样不幸。**
2010年8月接手，正是2008年暴跌后反弹行情的尾声。
随后A股进入漫长的阴跌期。刘彦春管理了近4年，
这期间不仅没赚钱，还亏了5%。[来源：同前]

有个让人哭笑不得的对比：在他离开后，
接任者王雪峰在243天内做到了30.87%的正收益——
"徒弟打败了师傅"。[来源：金融虎，千亿基金重仓360亿白酒]

在博时的7年，刘彦春管理的两只基金全部跑输同类平均，
在同类排名中处于中下游甚至垫底水平。

**如果用一句话总结：刘彦春在博时的七年，是一个"倒霉蛋"的故事。**

### 3.2 转折：2015年跳槽景顺长城

2014年6月，刘彦春离开博时基金。
2015年1月，他加入景顺长城基金。

他的跳槽时机谈不上好——2015年恰好是A股杠杆牛市的尾声。
从他接管景顺长城新兴成长混合（2015年4月）开始，
A股就经历了股灾（2015年6-8月）、熔断（2016年初）。

**所以，在2015-2016年，刘彦春的业绩依然是垫底的。**

### 3.3 封神：2017-2020年"白酒牛市"

2017年，市场风格发生转变。
以白酒为代表的大消费行业启动了漫长的上升周期。
刘彦春重仓的贵州茅台、泸州老窖、五粮液等涨幅均超60%。

他的代表作景顺长城新兴成长混合A，2017年收益位列同类前10%。
2019年收益72.18%、2020年收益85.94%——连续两年的超高回报，
吸引了天量的资金涌入。

**从2017年到2020年，刘彦春的规模从不到20亿飙升至1,163亿——5年增长了58倍。**

基民们称他为"春哥"，媒体把他和张坤并列"白酒双雄"。
"全世界最好的春春，不是李宇春，不是陈小春，而是刘彦春。"
这句流传在基民圈的话，最能说明他当时的人气。[来源：新浪财经，《大器晚成的消费狂魔》]

### 3.4 陨落：2021年至今

2021年春节后，市场风格突变。
"喝酒吃药"行情结束，新能源、AI成为新主线。
但刘彦春的持仓几乎没有变化——仍然是白酒+消费白马。

2021年-2025年，刘彦春管理的所有基金累计亏损424.7亿元。
规模从1,163亿缩水到265.50亿。同类排名全部垫底。

### 3.5 一个偶然的成功者？

回顾刘彦春的职业生涯，一个让人不安的事实浮现出来：

**他成功的核心因素，不是选股能力，不是择时能力，而是"押对了赛道+赶上了风口"。**

- 在博时的7年：尝试各种行业轮动 → 全部失败
- 在景顺长城的前2年：同样平庸
- 2017-2020年：重仓消费 → 刚好赶上超级周期

他是**"风口上的猪"理论**的教科书级案例——不，比那更复杂一点：
他在风口之前已经在风口的位置坐了很久，只是之前刮的是逆风。
但当顺风来临时，他因为"坐得久"而第一个飞了起来。

问题是：**当风停了，他还坐在原地。**
