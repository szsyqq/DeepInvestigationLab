# 评估团 · 争议视角

> 角色：质疑者

## 空客最不希望外界讨论的话题

1. **对普惠发动机的深度依赖**：为什么空客让一家美国供应商卡住40%的窄体机产能？A320neo有两个发动机选项（普惠GTF和CFM LEAP），但空客没有有效管理双源供应风险。
2. **产能爬坡的真实情况**：空客已经连续三年下调交付目标（2022→2024→2025），每次都说"供应链问题"，但问题看起来不像暂时的。Rate 75目标从2025年推迟到2027年。
3. **A320机身蒙皮质量事件**：2025年12月EASA发布适航指令，A320前机身蒙皮厚度不达标——这暴露了供应链质量管理的问题，收购Spirit AeroSystems正是为了解决这类问题，但收购本身也带来了整合风险。

## 公开说法与实际数据的裂缝

| 空客说法 | 实际数据 |
|---------|---------|
| "全球需求强劲" | 订单确实强劲，但2026年Q1交付量同比下降16%（136→114架） |
| "产能爬坡按计划推进" | Rate 75从2025→2027年，A220 rate 13从2026→2028年 |
| "防务与航天业务成功转型" | 2024年太空业务减记13亿欧元，转型靠的是裁减3000个岗位 |
| "2026年指导目标保持不变" | 但前提假设是"无额外重大干扰"——这个假设本身就很脆弱 |
| "中国是重要的战略合作伙伴" | 中国同时全力支持C919，2025年C919获1500+架订单 |

## 监管/媒体/行业对手提出的问题

- **波音复苏**：波音2025年交付600架（接近翻倍），Q1 2026更是143架超过空客的114架——这是2018年以来首次。
- **C919加速**：国产CJ-1000A发动机预计2026年下半年装机，届时C919将不再依赖LEAP-1C。一旦EASA认证通过...。
- **EASA对A320机身的适航指令**：暴露了供应链质量管理问题。
- **Project Bromo反垄断阻力**：德国OHB已威胁法律挑战，称合并"扰乱市场"。

## 空客不愿意回答的三个问题

1. 如果普惠不改善交付，空客的Plan B是什么？能否快速切换更多A320neo到CFM LEAP发动机？
2. 8754架积压订单中，有多大比例是"真正的"订单（有定金、有时间表）？多大比例是框架性意向？
3. 中国市场55%的份额能维持多久——如果EASA配合中国推动C919国际化？
