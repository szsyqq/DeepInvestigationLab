# 彩票资金的构成及其比例（中国福彩网）

- **2004年之前** 统一比例：彩票奖金占50%、彩票发行费占15%、彩票公益金占35%。
- **财综[2015]94号** 规定：彩票公益金比例最低不得低于20%；传统型、即开型发行费比例最高不超15%；乐透型、数字型、竞猜型、视频型、基诺型发行费比例最高不超13%。
- **各玩法资金构成比例（奖金 / 公益金 / 发行费）：**
  - 即开型：65% / 20% / 15%
  - 双色球：51% / 36% / 13%
  - 七乐彩：50% / 37% / 13%
  - 3D：53% / 34% / 13%
  - 快乐8：58% / 30% / 12%
