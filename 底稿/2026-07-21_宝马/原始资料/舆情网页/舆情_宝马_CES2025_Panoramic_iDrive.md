# 宝马 CES 2025：全新 BMW Panoramic iDrive 与 Heart of Joy

（宝马集团新闻稿，慕尼黑/拉斯维加斯，2025年1月7日）

## Panoramic iDrive（CES 2025 全球首发）
宝马在2025年国际消费电子展（CES）展示接近量产的新一代 iDrive，核心为 BMW Panoramic Vision（视平线全景显示）。底层软件为全新 BMW Operating System X。该整体系统自2025年底起导入所有新宝马车型。

四大融合元素（一致性的驾驶者聚焦）：
1. **BMW Panoramic Vision**：宝马自研的抬头显示新概念，将信息从A柱到A柱投射于风挡下部黑色涂层，所有乘员可见；关键驾驶信息投射于驾驶者视线左侧（左驾车型）。
2. **BMW 3D Head-Up Display（可选）**：位于 Panoramic Vision 上方，整合导航与自动驾驶信息。
3. **中控屏**：矩阵背光技术 + QuickSelect，自由剪裁设计靠近方向盘；最多可将6个小组件（widgets）滑动至 Panoramic Vision。
4. **多功能方向盘**：采用 shy-tech 理念，相关按键在可用时点亮，提供主动触觉反馈。

- BMW Operating System X 为宝马完全自研，基于 AOSP（Android Open Source Project）软件栈，较上一代更新/升级能力更强、向后兼容。
- 开发阶段在可用性实验室招募约3,000名客户参与；全球联网宝马车队已超2,200万辆。
- 智能个人助理将接入大语言模型（LLM），初期聚焦导航的自然语言指令。

## Heart of Joy（驾控超级大脑）
（补充自宝马官网 Heart of Joy 专题页，2025年）
- "Heart of Joy" 是将驱动（drivetrain）与驾驶动态（driving dynamics）功能整合于单一强大单元的新中央计算机，将随首款纯电 Neue Klasse 车型搭载于每一台纯电宝马。
- 负责驱动、制动、充电、能量回收与部分转向功能；信息处理速度较上代系统快10倍，延迟达毫秒级。
- 与 BMW Dynamic Performance Control 软件协同，将驾驶乐趣提升至新高度；日常行驶中约98%时间仅靠能量回收制动即可，无需摩擦制动，能效提升最高达25%。
- 法兰克·韦伯（Frank Weber）称其为"高效动力 squared（Efficient Dynamics squared）"。
