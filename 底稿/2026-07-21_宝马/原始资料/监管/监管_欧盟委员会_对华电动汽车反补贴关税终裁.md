# 欧盟委员会：对华产电动汽车反补贴关税终裁税率（2024年10月）

（欧盟委员会新闻稿，2024年10月29日；实施条例 (EU) 2024/2754，2024年10月29日，OJ L 2754）

## 措施概要
- 欧盟委员会结束反补贴调查，对原产于中华人民共和国的进口新电池电动汽车（BEV，CN 代码 ex 8703 80 10 / TARIC 8703 80 10 10）征收**为期五年**的最终反补贴税。
- 依据实施条例 (EU) 2024/2754，**自 2024年10月30日起适用（entry into force）**。
- 调查结论：中国 BEV 价值链受益于不公平的政府补贴，对欧盟 BEV 生产商造成经济损害威胁。
- 2024年7月4日征收的临时反补贴税不予征收；最终税项自生效之日起征收（可依规申请退税）。

## 最终反补贴税率（五年）
| 企业 / 类别 | 最终反补贴税率 |
|------|------|
| 比亚迪集团（BYD Group） | **17.0%** |
| 吉利集团（Geely Group） | **18.8%** |
| 上汽集团（SAIC Group） | **35.3%** |
| 特斯拉（上海）有限公司（经单独审查申请） | **7.8%** |
| 其他合作公司（附录列明） | **20.7%** |
| 所有其他不合作公司 | **35.3%** |

- 适用条件：须向成员国海关提交含有效商业发票的申报（TARIC 附加码，如 BYD 89HH 等；进口申报附加码 D008），并由开票方授权人员签署声明；未提交者按"所有其他公司"最高税率计征。
- 措施到期前可发起期满复审；任一合作出口商可申请加速复审以确定单独税率。

## 背景
- 该调查由欧委会主席冯德莱恩于 2023年9月13日（盟情咨文）宣布启动。
- 终裁投票：2024年10月4日，欧盟成员国以 10 票赞成、5 票反对、12 票弃权，未能阻止征税提案；德国投反对票。
- 欧委会同期仍表示愿与中方就"价格承诺"等 WTO 兼容方案谈判。
